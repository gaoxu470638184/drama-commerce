# 视频生成提示词方言（按模型）

## 通用提示词结构（六段式）

```
[主体] + [动作] + [环境] + [运镜] + [光线/风格] + [约束尾]
```

示例：
> 一位穿灰色家居服的年轻女性，惊讶地看着抽屉里拿出的小型破壁机并按下按钮，现代厨房晨光，手持跟拍微晃，自然光暖调，真实质感——不抖动、不变形、商品外观与参考图一致、画面无文字水印

## 约束尾词库（每个提示词必带）

中文：`画面稳定不抖动，人物手部不变形，商品外观与参考图完全一致，画面中不出现任何文字水印字幕`
英文：`stable camera, no hand distortion, product identical to reference image, no text or watermark on screen`

## 即梦 Seedance

- 输入限制：图片 ≤9 张（每张 <30MB）、视频 ≤3 个、总文件 ≤12；输出 4-15s，480p-720p
- **不支持写实真人脸部素材**（图/视频都会被拦截）→ 真人脸镜头用文生视频或换数字人工具
- 图生视频优先用于商品特写镜头；写中文提示词即可，需要英文时先翻再优化
- 多镜头序列：一个提示词内用 `镜头1：… 镜头2：…` 编排，控制总时长

## 可灵 Kling

- 强项：运镜控制、长镜头、物理真实感
- 提示词分层：主体描述（外观细节尽量具体到颜色材质）→ 动作 → 运镜指令（用标准词汇：推/拉/摇/移/跟）→ 氛围词
- 负面提示词固定带：`变形, 多余手指, 文字, 水印, 画面闪烁`
- 商品一致性：务必用图生视频 + 参考图，不要文生视频画商品

## Veo / Sora

- 英文提示词响应更好；支持对白时在提示词中用 `说："…"（中文）` 指定台词与音色描述
- Veo 强项：原生音效和对白；Sora 强项：复杂场景连贯性
- 单条 8s（Veo）为主力精修单位，长片段拆条生成

## 商品镜头专用模板（图生视频）

```
以参考图中的[商品名]为主体，[人物动作]使用它，[环境一句话]，
[运镜]，产品标识清晰可见且与参考图一致，真实使用场景质感，
—— [约束尾]
```

## 抽卡纪律（省钱的硬规则）

1. 一次生成 2-3 个变体挑选，不要无限重抽；单镜头重抽上限 3 次，仍不行 → 改分镜（换景别/换动作）而不是改提示词硬刚
2. 手部特写约 1/3 概率崩坏：崩了直接重抽，不要试图用提示词修
3. 素质优先级：商品外观一致 > 人物动作合理 > 光影氛围。商品画错 = 废片，重抽
4. 执行前把"预计生成条数 × 单价"列给用户确认

## 配音与字幕

- TTS 音色选型口诀：宝妈带货=温柔偏快，数码=低沉利落，零食=元气偏高
- 语速 1.05-1.15x（平台用户习惯倍速感）；句间留 150-250ms
- 字幕文件：生成 SRT，剪辑时逐句上屏；关键卖点词单独放大或变色
