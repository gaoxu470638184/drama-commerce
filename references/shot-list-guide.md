# 分镜表规范

## 分镜表格式

| 镜号 | 时长 | 景别 | 运镜 | 画面内容 | 台词/字幕 | 素材来源 | 商品处理 |
|-----|------|------|------|---------|----------|---------|---------|
| SC01 | 2s | 特写 | 手持固定 | 粥溢出锅沿，手忙脚乱擦台面 | 「完了完了」 | AI生成 | 无 |
| SC02 | 5s | 中景 | 固定 | 主角疲惫瘫坐，看满桌待做饭材 | 字幕：每天下班最怕这一刻 | 实拍/素材 | 无 |
| SC06 | 4s | 特写 | 缓推 | 主角从抽屉拿出机器，按下按钮 | 「直到闺蜜塞给我这个」 | 图生视频 | 首次植入：品牌面清晰≥1s |

素材来源枚举：`AI生成` / `图生视频` / `实拍` / `已有素材` / `录屏` / `合成`(代码/PS)

## 景别节奏规则

- 相邻镜头景别必须变化；特写→中景→特写 → 改成 中景→特写→全景
- 商品首次出现前的镜头，景别从大到小收紧（全景→中景→特写），制造"聚焦感"
- 第 4 拍见证阶段至少一个"对比分屏"或"前后同机位"镜头（效果类商品的转化主力）
- 60s 成片镜头数参考：18-30 个；镜头过少=呆，过多=碎

## 运镜速查

| 运镜 | 适用 |
|-----|------|
| 固定/手持微晃 | 对话、日常（UGC 质感首选） |
| 缓推 | 商品揭晓、情绪聚焦 |
| 快切+推拉 | 见证段节奏、卖点连击 |
| 跟拍 | 开箱、使用过程 |
| 甩镜转场 | 钩子段、时间跳切 |

## 商品植入规范

- 首次植入 = 道具位：商品在剧情动作里被"使用/发现/拿出"，禁止静态摆放+旁白念参数
- 特写时长 ≥ 1s，画面中品牌面清晰；但单镜头商品占画面 ≤ 1/3，不像广告
- 见证段商品自然入镜（手部动作带出），不让观众感觉镜头在"展示"
- 结尾 CTA 段才允许标准商品展示镜头（白底/场景图+价格字幕）

## UGC 质感清单（scrollclaw 精华）

- 首帧像手机随手拍：自然光、轻微噪点、生活背景杂物保留
- 台词有口头禅和语气词（"讲真""别笑""谁懂啊"），不用书面语
- 字幕样式：黑体白字黑描边（或平台热梗样式），逐句出现，关键词放大变色
- 允许"不完美"：轻微失焦、构图偏、手抖——过度精致=AI 味=划走

## 安全区（竖屏 9:16）

- 顶部 12% / 底部 20% / 右侧 15% 避开平台 UI（进度条、点赞栏、标题、购物车按钮）
- 关键信息和商品特写放画面中央 55% 区域
