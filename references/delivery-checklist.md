# 交付自检清单

逐项打分后输出报告（`06-review.md`），总分 = 病毒度分（见文末）。

## 一、红线项（任一不过 = 打回重做）

- [ ] **违禁词扫描**：全片台词/字幕/口播无「最、第一、国家级、治愈、根治、百分百、秒杀（平台敏感义）、全网最低价」及医疗功效类绝对化表述
- [ ] **虚假宣传**：效果对比未夸大到失实；价格/规格/赠品与店铺实际一致；无虚构限量/倒计时
- [ ] **版权**：商品图、BGM、字体均为可商用或已授权素材；不搬运他人视频画面
- [ ] **商品一致性**：AI 生成镜头里商品外观与实物一致（颜色、logo、形状），无模型瞎编
- [ ] **钩子兑现**：前 3 秒承诺的剧情/效果在片内出现

## 二、结构项

- [ ] 前 1 秒有动作/冲突/异常
- [ ] 前 3 秒完成人群锁定或悬念成立
- [ ] 商品首次出现在第 3 拍反转处，且是道具位不是展示位
- [ ] 见证段有前后对比或使用过程实感
- [ ] 结尾 CTA 明确且 ≤ 10s，不拖泥带水
- [ ] 全片只有一个主卖点，辅助卖点 ≤ 3 个

## 三、技术项

- [ ] 规格：9:16 竖屏（抖音/快手/视频号/小红书）；分辨率 ≥ 1080×1920
- [ ] 安全区：右侧点赞栏、底部标题/购物车、顶部无遮挡
- [ ] 字幕：逐句对齐人声，无错别字，关键卖点强调处理
- [ ] 音量：口播 -14 LUFS 左右，BGM 不压人声（人声清晰度优先）
- [ ] 首帧即内容，无黑帧/白帧开头

## 四、病毒度评分（10 分制）

| 维度 | 分值 | 判据 |
|------|-----|------|
| 钩子强度 | 3 | 自测：刷到这条会不会停？（诚实自评，默认不过） |
| 情绪曲线 | 2 | 有无明确共鸣点+反转点，还是平铺直叙 |
| 卖点清晰度 | 2 | 不暂停的情况下能记住几个卖点（能记住 1 个 = 满分） |
| 转化引导 | 2 | CTA 是否具体、低成本（"点左下角"好过"支持一下"） |
| 质感匹配 | 1 | 质感符合目标平台调性（UGC 感 vs 精致感） |

**≥ 7 分交付；5-6 分给出 1-2 处具体修改建议（通常是钩子或前 20 秒）后交付；< 5 分打回，先改剧本。**

## 五、交付物清单

- [ ] 成片（mp4）
- [ ] 全部中间文件：brief / 卖点 / 钩子 / 剧本 / 分镜 / 提示词 / 自检报告
- [ ] A/B 测试建议：至少 2 个备选钩子的前 3 秒变体（可直接换头重剪）
- [ ] 投放观察指标：3s 完播率、整体完播率、点击率、转化率——24-48h 后复盘哪个钩子假设成立
