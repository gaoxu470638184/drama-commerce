## 最有价值的三条经验

1. **卖点不是商品属性，是行业反差**。「9 种高品质坚果」人人会说；「同价位别人掺果干，这个不掺」才是能被验证的差异。
2. **AI 一定画不对包装文字**。测试中 AI 生成的礼盒包装文字全部变成乱码。最终方案：人物/氛围镜头用 AI，**商品特写用真图定格 + ffmpeg 缓慢推镜**，零失真零成本。
3. **单条片只赌一个钩子假设**。三条片不是「三个版本的故事」，是三个可独立归因的实验。
