# 03 - 剧本 ep03「楼下等快递」（钩子 H3：剧情钩子）

时长目标 80s ｜ 角色：儿子大伟（异地，只出声音）/ 爸（62 岁）/ 妈 / 小孙子（背景）｜ 商品植入位：第 3 拍

## 第 1 拍｜钩子（0-3s）

- 场景 1：冬日清晨小区门口，老爹穿棉袄踮脚看快递柜，来回踱步搓手。
- 字幕：爸说"别再寄东西了"，人却在楼下等了半小时。

## 第 2 拍｜共鸣（3-22s）

- 场景 2：前夜客厅，爸冲电话喊。
  台词：「别寄了别寄了！家里的东西吃不完！」（挂电话后转头问妈：「寄的是啥？」）
- 场景 3：妈翻白眼：「你猜。」
- 字幕：口是心非，全国爸妈统一行为。

## 第 3 拍｜反转/发现（22-42s）★首次植入

- 场景 4：快递柜开门，爸抱箱上楼，路上就想拆。
- 场景 5：客厅开箱，**礼盒正面特写 1s**，爸愣了一下。
  爸：「坚果啊……」
- 场景 6：**掀盖，9 格俯拍完整露出**，妈凑过来「嚯，9 样」。

## 第 4 拍｜见证（42-70s）辅助卖点：品质 + 全家能吃

- 场景 7：爸捻一粒腰果入口，眯眼点头，不说话但一直伸手拿（嘴硬手诚实）。
  爸（翻找）：「怎么没葡萄干？」
  妈：「人家这是纯坚果，不给你凑数。」
- 场景 8：爸捏起一袋独立小包看背面，塞进棉袄口袋。
  妈（小声）：「出门遛弯都要带一包。」
- 场景 9：孙子跑过来抓了一把，爸喊「慢点吃，还有 8 样！」
  妈（对镜头小声）：「嘴上说别寄，一顿饭下去半盒没了。」
- 场景 10：晚上爸给大伟回视频，背景是摆好的坚果盘。
  爸（别扭地）：「下回……别寄别的了，就寄这个。」

## 第 5 拍｜转化（70-80s）

- 场景 10：坚果盘+礼盒+三代同框暖光，字幕：9 种坚果 · ¥59.9 · 年货价。
- 大伟 OS：「爸妈要的从来不是贵，是你想着他们。59 块 9，寄回家——点下方链接。」

## 台词自检

- 口语化 ✅｜无违禁词 ✅｜钩子兑现（等的正是礼盒）✅｜结尾埋"转发家庭群"情绪点 ✅
