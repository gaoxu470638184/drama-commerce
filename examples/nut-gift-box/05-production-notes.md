- **严禁使用用户提供的 某竞品竞品图**（含他牌 logo + 含果干 + ¥99，三项全部冲突）

**ep02-07（独立小包）**：
> 一只手撕开银色独立小包装袋，将里面的混合坚果倒在掌心，特写，柔和窗光，轻微手持感——包装外观与参考图一致，手部结构正常不变形，画面无文字水印

**ep03-01（钩子）**：
> 冬日清晨中国北方小区门口，一位穿深蓝色棉袄的六十二岁男性踮脚查看快递柜并来回踱步搓手，呵出白气，固定机位，自然冷调晨光，真实纪录片质感——画面稳定，人物动作自然，无文字水印

## 四、配音方案

- ep01：女儿=年轻女声偏快（zh-CN-XiaoxiaoNeural）；妈=中老年女声偏慢
- ep02：儿子=青年男声爽利（zh-CN-YunxiNeural）；爸=低沉慢速
- ep03：爸=主角音色，需"别扭感"→ 语速 0.95x + 句尾上扬少
- 全员语速基准 1.1x（视频号用户习惯），关键卖点句降回 1.0x 强调

## 五、剪辑与字幕

- 首选剪映专业版自动时间轴（若装 jianying-editor-skill 可全自动）；兜底 ffmpeg 拼接 + SRT 烧录
- 字幕：黑体白字黑描边，卖点词（9 种 / 59.9 / 饱满）放大 + 金色
- BGM：温情钢琴（ep01/ep03）、轻快节奏点（ep02）；音量压至人声 -12dB 以下
- 安全区：9 格俯拍和价格字幕避开右侧点赞栏与底部标题区

## 六、执行顺序建议

1. 用户确认规格 + 提供商品图
2. 先生成 3 个钩子镜头样片（ep01-01 / ep02-01 / ep03-01）验证风格
3. 通过后批量生成 → 配音 → 剪辑 → 走 06 自检 → 交付
